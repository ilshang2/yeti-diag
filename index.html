能做什麼

  • 全車掃描：新舊模組的零件號碼、編碼、故障碼 (含說明，與 VCDS 對照過)
  • 引擎即時數據、各缸失火次數、排放自我檢測
  • 即時儀表：只讀引擎，開車時也可以看、可以存檔
  • 09 中央電子隱藏功能讀取與開關 (寫入為實驗功能)
  • 每個指令都能輸出 JSON，也有 MCP 伺服器，方便 AI 操作

使用前請看

使用風險自負。寫入可能讓功能失效或產生故障碼；只在作者的一台 Skoda Yeti 1.2 TSI 2014 上驗證過。 行駛中只能看即時儀表：車速超過 3 km/h 時程式會拒絕連 ABS 等模組與任何寫入。 與 Volkswagen、Škoda、Ross-Tech 無關。不提供改里程、防盜破解。

幫忙測試

先只用讀取功能，再填 「回報我的車」表單：車型、接頭、哪些正常。成功、失敗都請回報，失敗的最有幫助。貼任何東西前請刪掉車身號碼 (VIN)。不是 Yeti 的車怎麼加入，見 參與說明。

Source / CLI

Python tool, simulator, tests and full docs.

GitHub

What it does

  • Whole-car scan: part numbers, coding and decoded fault codes of new and old modules (checked against VCDS)
  • Engine live data, misfire counters per cylinder, emission readiness
  • Live dashboard: engine only, safe to watch while driving, can log to a file
  • Read and switch 09 hidden features (writing is experimental)
  • JSON output for every command and an MCP server for AI agents

Screenshots

Taken on the built-in simulator; the program's labels are in Chinese.

Before you start

Use at your own risk. Writes can disable functions or set fault codes; verified on one Skoda Yeti 1.2 TSI 2014 only. While driving, use only the live dashboard: above 3 km/h the tool refuses ABS and other modules and every write. Not affiliated with Volkswagen, Škoda or Ross-Tech. No odometer or immobilizer features.

Help test

Start with reads only, then fill in the car report form: car, adapter, what worked. Success or failure both help — failures most. Remove your VIN before posting. Adding a car other than the Yeti: how to contribute.
